# 🌐 Tiara Sari Dewi — Personal Portfolio

Welcome to the source code of my personal portfolio. This site showcases my work, skills, and passion as a developer. It features a clean, responsive design with a dark/light mode toggle and was crafted entirely by me.

## ✨ Features

- ⚡ Built with Next.js (React-based framework)
- 🎨 Custom fonts: **Parkinsans** and **Source Code Pro**
- 🌗 Dark and Light mode toggle
- 📱 Fully responsive design for all devices
- 🧩 Minimal and modern UI
- 💻 Easily customizable

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [SCSS](https://sass-lang.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Google Fonts](https://fonts.google.com/) (Parkinsans & Source Code Pro)

## 🚀 Getting Started

To run this project locally:

### Clone the repo
git clone https://github.com/trsrdw/portfolio.git

### Navigate to the project directory
cd portfolio

### Install dependencies
npm install

### Start the development server
npm run dev

The app will be running at http://localhost:3000
